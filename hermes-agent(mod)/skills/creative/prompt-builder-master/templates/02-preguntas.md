# 02 — Preguntas de Indagación

Genera 5–10 preguntas breves, adaptadas al proyecto. Cada una con 2–4 opciones visuales/funcionales coherentes.

## Formato

### 1. [Pregunta]
- A) [opción visual/funcional]
- B) [opción]
- C) [opción]

### 2. [Pregunta]
- ...

---

## Categorías sugeridas

- **Paleta**: ¿cálida o fría? ¿neutra o con acento fuerte?
- **Tipografía**: ¿serif editorial o sans técnico?
- **Hero**: ¿inmersivo o informativo? ¿estático o interactivo?
- **Navegación**: ¿sticky o fade-in? ¿con mega-menú o minimal?
- **CTA principal**: ¿una acción o varias? ¿dónde?
- **Contenido visual**: ¿fotografía real, ilustración custom, 3D, o mix?
- **Motion**: ¿sutil o expresivo? ¿con scroll triggers?
- **Dark mode**: ¿existe un toggle o solo light por defecto?
- **Accesibilidad**: ¿WCAG AA o AAA?
- **Idioma**: ¿mono o multi-idioma?
